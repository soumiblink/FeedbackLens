# FeedbackLens - Quick Start Guide

## 🚀 Get Started in 5 Minutes

### Step 1: Start Backend
```bash
cd backend
python main.py
```
**Backend running at:** http://localhost:8000

### Step 2: Start Frontend
```bash
cd frontend
npm run dev
```
**Frontend running at:** http://localhost:5173

### Step 3: Upload Feedback
1. Navigate to http://localhost:5173
2. Click "Upload Feedback"
3. Upload a CSV file or paste text
4. Wait for analysis to complete

### Step 4: Explore Features
- **Product Health** - View overall health score
- **Feedback Inbox** - Browse all feedback
- **Prioritization** - See top opportunities
- **Roadmap** - Plan your product roadmap
- **Release Impact** - Compare releases

## 🎯 Common Workflows

### Daily Check
1. Open **Product Health**
2. Check health score
3. Review top risk
4. Check trend

### After Upload
1. View **Dashboard** for overview
2. Browse **Feedback Inbox** for details
3. Check **Prioritization** for opportunities

### Planning Sprint
1. Review **Prioritization**
2. Add opportunities to **Roadmap**
3. Update status as work progresses

### After Release
1. Upload new feedback batch
2. Go to **Release Impact**
3. Compare before/after
4. Check health score change
